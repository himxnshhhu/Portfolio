File Organizer

File Organizer is a Python based automation project designed to simplify the process of managing cluttered directories and large collections of files. The system scans a selected folder and identifies files based on their extensions and file types. It then automatically sorts and moves them into structured categories, creating a cleaner and more organized workspace. Built using Python's OS and Shutil libraries, the project focuses on practical automation, efficient file handling, and reducing repetitive manual work. The system successfully organized 271+ files across 15+ categories while maintaining accurate classification and zero observed sorting errors.

Coupon Drops

Coupon Drops is a responsive coupon discovery platform created to make finding relevant deals faster and easier. The platform uses HTML, CSS, and JavaScript to present coupon listings through a clean and intuitive interface that adapts across desktop and mobile devices. A real time search and filtering system allows users to quickly narrow down more than 20 coupon listings based on their requirements. The interface follows a mobile first approach with responsive layouts and cross browser compatibility to provide a consistent browsing experience. The project also focuses on usability and efficient interaction, improving the overall coupon discovery process and reducing the effort required to find relevant offers.
